# Booth_Multiplier_algorithm_fpga
This project implements a Signed Booth Multiplier on the Nexys 4 DDR FPGA board using Verilog HDL.

The design performs signed binary multiplication using the Booth Multiplication Algorithm, which reduces the number of required arithmetic operations by encoding consecutive 1s in the multiplier.

● Objectives :

•Implement the Booth Multiplication Algorithm in Verilog HDL.

•Perform signed binary multiplication.

•Verify the multiplier using simulation.

•Synthesize and implement the design on the Nexys 4 DDR FPGA.
